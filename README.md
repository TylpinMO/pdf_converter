# PDF Converter

Telegram-бот на Python для объединения фотографий в PDF и преобразования страниц PDF в JPG.

## Возможности

- До 20 фотографий в одном PDF с сохранением порядка.
- PDF → JPG: отдельное изображение для каждой страницы.
- Счётчики операций, блокировка пользователей и безлимитный режим в SQLite.
- Проверка подписки на настраиваемый канал.
- Административное меню со статистикой и рассылкой.

Стек: Python, aiogram, aiosqlite, Pillow и PyMuPDF. Основной PDF-движок — **PyMuPDF**: для обычной установки Poppler не нужен.

## Запуск

Проверяемая версия окружения — Python 3.12.

```bash
git clone https://github.com/TylpinMO/pdf_converter.git
cd pdf_converter
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
```

Для Windows: `.venv\Scripts\Activate.ps1` и `Copy-Item .env.example .env`.

Заполните `BOT_TOKEN`, `ADMIN_ID` и `CHANNEL_USERNAME` своими значениями. Боту нужны права администратора в указанном канале для проверки подписки пользователей.

```bash
python bot.py
```

База `bot.db`, журналы и временные документы создаются локально и исключены из Git. [Запуск на сервере](DEPLOYMENT.md).

## Проверки

```bash
python -m unittest discover -s tests -v
```

Тесты создают изображения и БД во временных каталогах, без личных документов и Telegram-запросов. Проверяются порядок страниц, прозрачность изображений, границы размера файла, очистка файлов, регистрация, блокировки и параллельное увеличение счётчика. Те же проверки запускаются в GitHub Actions на Linux и Windows.

## Устройство

- `handlers/` — пользовательские и административные сценарии.
- `utils/pdf_converter.py` — конвертация и очистка файлов.
- `database.py` — пользователи, статистика и настройки.
- `config.py` — параметры из окружения.
- `tests/` — автоматические проверки.

## Ограничения

Конвертация выполняется в процессе бота: большие документы могут задерживать обработку других сообщений. Для нагрузки потребуется отдельная очередь обработки. Заданные в конфигурации размеры файлов не отменяют ограничений Telegram Bot API.

Состояние незавершённых диалогов хранится в памяти. Перезапуск прерывает текущую загрузку; доставку файлов и очистку после прерванных сессий следует отдельно проверить на тестовом боте. CI не выполняет реальную рассылку и не подтверждает готовность к большим нагрузкам.
