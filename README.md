# 📄 PDF Bot - Telegram Бот для конвертации фото и PDF

Telegram бот для конвертации фотографий в PDF и разбиения PDF на отдельные изображения с системой лимитов и админ-панелью.

## 🎯 Основные возможности

### Для пользователей:

- **📷 → PDF**: Конвертация до 20 фотографий в единый PDF-документ
- **📄 → 📷**: Разбиение PDF на отдельные JPG изображения (по страницам)
- **⚡ Быстрая обработка**: Мгновенная конвертация файлов
- **🔒 Безопасность**: Все файлы удаляются после обработки

### Для администратора:

- **📊 Статистика**: Полная аналитика использования бота
- **👥 Управление пользователями**: Просмотр, снятие лимитов, бан
- **📢 Рассылка**: Массовая отправка сообщений с фото
- **⚙️ Настройки**: Изменение глобальных лимитов

## 🔑 Основные требования

- **Обязательная подписка на канал**: [@matvuktuk](https://t.me/matvuktuk)
- **Лимиты использования**: 10 операций в день (сброс в 00:00 МСК)
- **Размеры файлов**:
  - Фото: до 15 МБ
  - PDF: до 100 МБ

## 🛠 Технологический стек

- **Python 3.9+**
- **aiogram 3.3.0** - асинхронная библиотека для Telegram Bot API
- **SQLite** - база данных для хранения пользователей и статистики
- **Pillow** - обработка изображений
- **PyPDF2** - работа с PDF файлами
- **pdf2image** - конвертация PDF в изображения
- **poppler** - системная зависимость для pdf2image

## 📦 Установка

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd pdf_bot
```

### 2. Создание виртуального окружения

```bash
python3 -m venv venv
source venv/bin/activate  # для Linux/macOS
# или
venv\Scripts\activate  # для Windows
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Установка системных зависимостей

**macOS:**

```bash
brew install poppler
```

**Linux (Ubuntu/Debian):**

```bash
sudo apt-get install poppler-utils
```

**Windows:**
Скачайте poppler с [официального сайта](http://blog.alivate.com.au/poppler-windows/) и добавьте в PATH

### 5. Настройка окружения

Создайте файл `.env` в корне проекта:

```env
BOT_TOKEN=your_bot_token_here
ADMIN_ID=740416524
CHANNEL_USERNAME=@matvuktuk
DAILY_LIMIT=10
MAX_PHOTO_SIZE_MB=15
MAX_PDF_SIZE_MB=100
```

**Получение токена бота:**

1. Найдите [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям
4. Скопируйте полученный токен в `.env`

## 🚀 Запуск

```bash
python bot.py
```

Бот запустится в режиме polling и будет готов к работе.

## 💾 База данных

Бот использует SQLite с тремя таблицами:

### users

| Поле              | Тип                 | Описание                 |
| ----------------- | ------------------- | ------------------------ |
| user_id           | INTEGER PRIMARY KEY | ID пользователя Telegram |
| username          | TEXT                | Username пользователя    |
| first_name        | TEXT                | Имя пользователя         |
| registration_date | TIMESTAMP           | Дата регистрации         |
| is_unlimited      | BOOLEAN             | Снят ли лимит            |
| is_banned         | BOOLEAN             | Забанен ли пользователь  |

### usage_stats

| Поле             | Тип                 | Описание            |
| ---------------- | ------------------- | ------------------- |
| id               | INTEGER PRIMARY KEY | ID записи           |
| user_id          | INTEGER             | ID пользователя     |
| date             | DATE                | Дата использования  |
| operations_count | INTEGER             | Количество операций |

### settings

| Поле  | Тип              | Описание           |
| ----- | ---------------- | ------------------ |
| key   | TEXT PRIMARY KEY | Ключ настройки     |
| value | TEXT             | Значение настройки |

## 📱 Использование

### Для пользователей:

1. **Начало работы**: Отправьте `/start` боту
2. **Проверка подписки**: Подпишитесь на канал [@matvuktuk](https://t.me/matvuktuk)
3. **Конвертация фото в PDF**:
   - Нажмите кнопку "📷 → PDF"
   - Отправьте от 1 до 20 фотографий
   - Нажмите "✅ Создать PDF"
   - Получите готовый PDF-файл
4. **Конвертация PDF в фото**:
   - Нажмите кнопку "📄 → 📷"
   - Отправьте PDF-файл (до 100 МБ)
   - Получите изображения каждой страницы в формате JPG

### Для администратора:

**Доступ к админ-панели**: `/admin`

**Разделы админ-панели:**

1. **📊 Статистика**:
   - Общее количество пользователей
   - Активные пользователи сегодня
   - Операции за день/неделю/месяц
   - Пользователи с безлимитом

2. **👥 Пользователи**:
   - Список всех пользователей с пагинацией (по 10)
   - Просмотр деталей каждого пользователя
   - Снятие/возврат лимита
   - Бан/разбан пользователя

3. **📢 Рассылка**:
   - Отправка текста или текста с фото всем пользователям
   - Подтверждение перед отправкой
   - Отчет о доставке

4. **⚙️ Настройки**:
   - Изменение глобального лимита операций
   - Настройки не влияют на пользователей с безлимитом

## 🔐 Безопасность

- Все временные файлы удаляются после обработки
- Токен бота хранится в `.env` (не в git)
- Доступ к админ-панели только по ID администратора
- Проверка подписки перед каждой операцией
- Логирование всех критических операций

## 📝 Логирование

Все события записываются в файл `bot.log`:

- **INFO**: Обычные операции (запуск, конвертация)
- **WARNING**: Предупреждения (превышение лимита, ошибки подписки)
- **ERROR**: Критические ошибки (ошибки конвертации, БД)

## ⚠️ Ограничения

- Максимум 20 фотографий за одну операцию
- Размер фото: до 15 МБ
- Размер PDF: до 100 МБ
- Лимит операций: 10 в день (сброс в 00:00 МСК)
- Формат выходных изображений: только JPG

## 🤝 Поддержка

При возникновении проблем:

1. Проверьте логи в файле `bot.log`
2. Убедитесь, что установлены все зависимости
3. Проверьте правильность настроек в `.env`
4. Убедитесь, что poppler установлен корректно
