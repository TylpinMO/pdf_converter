# Запуск на сервере

Используйте Python 3.12 и отдельного пользователя ОС. Рабочие токены и документы не должны попадать в репозиторий.

## Установка

```bash
git clone https://github.com/TylpinMO/pdf_converter.git
cd pdf_converter
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp .env.example .env
chmod 600 .env
```

Заполните `.env` своими `BOT_TOKEN`, `ADMIN_ID`, `CHANNEL_USERNAME` и лимитами. Основная установка использует PyMuPDF; Poppler не требуется.

## Проверка перед запуском

```bash
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python bot.py
```

На отдельном тестовом боте проверьте подписку, загрузку нескольких фото, обратную конвертацию PDF, дневной лимит и административное меню. Не используйте рабочие документы для проверки.

## Постоянная работа

Настройте менеджер служб, например systemd: рабочий каталог должен указывать на корень проекта, команда запуска — на `.venv/bin/python bot.py`. Запускайте только один polling-процесс с выбранным токеном.

Сохраняйте резервную копию `bot.db` перед обновлением, ограничьте доступ к `.env`, БД и временным файлам. Перед перезапуском завершайте текущие конвертации. Логи не следует публиковать без проверки на персональные данные.

Репозиторий не содержит подключения к рабочему серверу и не развёртывается на нём автоматически.
